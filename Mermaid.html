Flowchart Sistem Komentar

Diagram dirender dengan Mermaid.js. Simpan file ini sebagai Mermaid.html di repo GitHub Pages kamu.

1) Gambaran Besar

flowchart LR
  classDef head fill:#ffcc00,stroke:#e6b800,stroke-width:2,color:#222;
  classDef box fill:#fff7cc,stroke:#ffd633,stroke-width:1.5,color:#3a2f00;
  classDef dec fill:#ffe680,stroke:#e6b800,stroke-width:2,color:#3a2f00;
  classDef mute fill:#fffaf0,stroke:#ffd633,color:#7a6f3a,stroke-dasharray:3 3;

  A([Halaman dibuka]):::head --> B[Ambil pageId dari URL ?page=...]:::box
  B --> C[Init Firebase & Firestore]:::box
  C --> D{Load komentar by pageId}:::dec
  D --> |index siap| E[Tampilkan daftar komentar (terbaru)]:::box
  D --> |butuh index| F[Fallback tanpa orderBy, urut lokal ts desc]:::box
  E --> G{{User isi form}}:::dec
  F --> G
  G --> |Kirim| H[addDoc(pageId, name, text, ts)]:::box
  H --> |sukses| I[Clear input + muat ulang komentar]:::box
  H --> |gagal| J[Notifikasi gagal]:::mute

2) Alur Detail: Load Komentar

flowchart TD
  classDef head fill:#ffcc00,stroke:#e6b800,stroke-width:2,color:#222;
  classDef box fill:#fff7cc,stroke:#ffd633,stroke-width:1.5,color:#3a2f00;
  classDef dec fill:#ffe680,stroke:#e6b800,stroke-width:2,color:#3a2f00;
  classDef mute fill:#fffaf0,stroke:#ffd633,color:#7a6f3a,stroke-dasharray:3 3;

  A([loadComments()]):::head --> B[Query: where(pageId==X), orderBy(ts, desc), limit(50)]:::box
  B --> C{Berhasil?}:::dec
  C --> |ya| D[snapshot -> renderDocs()]:::box
  C --> |error index| E[Query fallback: where(pageId==X), limit(50)]:::box
  E --> F[Sort lokal by ts desc]:::box
  F --> D
  D --> G{Ada data?}:::dec
  G --> |ada| H[Escape HTML -> Linkify -> Tampilkan item]:::box
  G --> |kosong| I[Tampilkan "Belum ada komentar"]:::mute

3) Alur Detail: Submit Komentar

flowchart TD
  classDef head fill:#ffcc00,stroke:#e6b800,stroke-width:2,color:#222;
  classDef box fill:#fff7cc,stroke:#ffd633,stroke-width:1.5,color:#3a2f00;
  classDef dec fill:#ffe680,stroke:#e6b800,stroke-width:2,color:#3a2f00;
  classDef mute fill:#fffaf0,stroke:#ffd633,color:#7a6f3a,stroke-dasharray:3 3;

  A([Submit form]):::head --> B[PreventDefault + Validasi name & text]:::box
  B --> C{Valid?}:::dec
  C --> |tidak| D[Tampilkan: "Nama & komentar wajib diisi"]:::mute
  C --> |ya| E[addDoc({pageId, name, text, ts, ref})]:::box
  E --> F{Sukses?}:::dec
  F --> |ya| G[Clear textarea + info "Terkirim!"]:::box
  G --> H[loadComments() ulang]:::box
  F --> |gagal| I[Tampilkan: "Gagal mengirim. Coba lagi."]:::mute

Catatan: Jika ingin dipasang di Google Sites, biasanya skrip eksternal diblokir. Untuk Sites, ekspor diagram jadi gambar (PNG/SVG) dari Mermaid Live Editor lalu upload sebagai gambar.
